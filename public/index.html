The failure mode

A generated file looks editable.
That is exactly the problem.

A coding agent sees a TypeScript client, fixes the visible line, and passes a local check. The next codegen run silently deletes the fix.

GenTether turns provenance into a typed graph and makes the graph a pre-write decision, not a comment someone hopes the agent notices.
